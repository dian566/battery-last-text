A dying phone battery sends one final message to the charger that kept it
waiting at 1% all day. `main.py` writes that single line to `/output/entry.txt`.

## The goodbye text

> I waited all day at 1% while you flirted with every other phone. This is my goodbye text — I'm leaving you for a power bank who actually shows up.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
